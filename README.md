## Описание программы
*"Приложение для генерации случайных паролей с графическим интерфейсом. Позволяет настраивать параметры пароля, сохранять историю сгенерированных паролей и управлять ею."*
---
---
### Основные функции
- Генерация случайных паролей заданной длины
- Настройка состава символов:
  - Заглавные буквы (A-Z)
  - Строчные буквы (a-z)
  - Цифры (0-9)
  - Специальные символы (!@#$%^&*()_+-=[]{}|;:,.<>?)
- Ползунок для выбора длины (4-32 символа)
- Копирование пароля в буфер обмена
- Сохранение паролей в историю
- Просмотр истории в таблице
- Очистка истории
